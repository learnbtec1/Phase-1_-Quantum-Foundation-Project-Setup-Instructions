## 📋 نظرة عامة

نظام إدارة واجبات الطلاب هو تطبيق Python كامل مع واجهة رسومية (GUI) مصمم لمساعدة المعلمين والإداريين في:

- 📂 **تنظيم الواجبات** تلقائياً لكل طالب ومادة
- ⬆️ **رفع الملفات** بسهولة مع زر واضح ومميز
- 📝 **إنشاء ملفات التقييم** بشكل احترافي
- 🔄 **التنظيم الذكي** لملفات التقييم تلقائياً
- 📊 **متابعة التقدم** والإحصائيات لكل طالب

## ✨ الميزات

### 🎯 الميزات الأساسية

| الميزة | الوصف |
|--------|--------|
| **إدارة الطلاب** | إضافة، حذف، تصدير قوائم الطلاب بسهولة |
| **إدارة المواد** | إنشاء مواد دراسية وتسجيل الطلاب فيها |
| **رفع الواجبات** | واجهة بسيطة مع زر كبير لرفع جميع أنواع الملفات |
| **التقييم** | إنشاء ملفات تقييم مع درجات وتعليقات |
| **التنظيم التلقائي** | فرز وترتيب ملفات التقييم تلقائياً |
| **التقارير** | إحصائيات شاملة عن أداء الطلاب |

## 🚀 التثبيت

### المتطلبات الأساسية

- Python 3.6 أو أحدث
- نظام التشغيل: Windows, macOS, أو Linux
- مكتبة Tkinter (مدمجة مع Python)

### خطوات التثبيت

#### Windows:

```bash
# 1. انتقل لمجلد المشروع
cd student-assignment-system

# 2. قم بتشغيل ملف الإعداد
setup.bat
```

#### macOS/Linux:

```bash
# 1. انتقل لمجلد المشروع
cd student-assignment-system

# 2. أعط صلاحيات التنفيذ
chmod +x setup.sh

# 3. قم بتشغيل الإعداد
./setup.sh
```

#### التثبيت اليدوي:

```bash
# تثبيت المكتبات المطلوبة
pip install -r requirements.txt
```

## 💻 الاستخدام

### التشغيل السريع

```bash
# الطريقة الأولى: مع نافذة ترحيب
python run_system.py

# الطريقة الثانية: تشغيل مباشر
python main_gui.py
```

### سير العمل الأساسي

#### 1️⃣ إضافة الطلاب والمواد

```python
# في تبويب "إدارة الطلاب"
1. أدخل اسم الطالب
2. اضغط "إضافة طالب"

# أو إضافة عدة طلاب
1. اضغط "إضافة عدة طلاب"
2. أدخل أسماء الطلاب (سطر لكل اسم)
3. اضغط "حفظ"

# في تبويب "إدارة المواد"
1. أدخل اسم المادة واسم المعلم
2. اضغط "إضافة مادة"
3. اختر المادة وحدد الطلاب
4. اضغط "تسجيل الطلاب المحددين"
```

#### 2️⃣ رفع واجب طالب

```python
# في تبويب "رفع الواجبات"
1. اختر المادة من القائمة
2. اختر الطالب
3. اضغط "📁 اختر ملف الواجب"
4. أدخل اسم الواجب (اختياري)
5. اضغط الزر الأخضر الكبير "⬆️ رفع الواجب"
```

#### 3️⃣ تقييم واجب

```python
# في تبويب "التقييم"
1. اختر المادة والطالب
2. أدخل الدرجة (0-100)
3. اكتب تعليقات المعلم
4. أضف ملاحظات إضافية
5. اضغط "📝 إنشاء ملف التقييم"
```

#### 4️⃣ تنظيم الملفات تلقائياً

```python
# في تبويب "التنظيم التلقائي"
1. اختر المادة
2. اضغط "📁 اختر المجلد" (المجلد الذي يحتوي على ملفات التقييم)
3. اضغط "🔄 تنظيم الملفات تلقائياً"
4. راجع النتائج في نافذة النتائج
```

## 🎯 حالات الاستخدام

### مثال 1: إدارة مادة الرياضيات

```markdown
المعلم: الأستاذ خالد
المادة: الرياضيات
الطلاب: أحمد، سارة، علي

الخطوات:
1. إضافة المادة والطلاب
2. تسجيل الطلاب في المادة
3. رفع واجبات الطلاب (PDF, Word, صور)
4. تقييم الواجبات مع الدرجات
5. متابعة التقدم من خلال التقارير
```

### مثال 2: تنظيم ملفات التقييم

```markdown
الموقف: لديك 50 ملف تقييم متفرقة في مجلد واحد

الحل:
1. افتح تبويب "التنظيم التلقائي"
2. اختر المادة
3. اختر المجلد
4. اضغط "تنظيم"
5. النتيجة: كل ملف يذهب لمجلد الطالب الصحيح تلقائياً!
```

## 🐛 استكشاف الأخطاء

### المشكلة: الواجهة لا تظهر
```bash
# التأكد من تثبيت Tkinter
python -m tkinter
# إذا ظهرت نافذة، فكل شيء يعمل بشكل صحيح
```

### المشكلة: أخطاء ترميز (encoding)
```bash
# Windows
chcp 65001
python run_system.py

# macOS/Linux
export LANG=ar_SA.UTF-8
python3 run_system.py
```

### المشكلة: لا يمكن حفظ الملفات
```bash
# تحقق من الصلاحيات
# تأكد من أن المجلد قابل للكتابة

```
