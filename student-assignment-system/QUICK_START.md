# دليل البدء السريع 🚀

## 📦 تثبيت النظام

### للويندوز:
1. تأكد من تثبيت Python 3.6 أو أحدث
2. افتح مجلد المشروع
3. انقر نقراً مزدوجاً على `setup.bat`
4. انتظر حتى يكتمل التثبيت

### للماك/لينكس:
```bash
# افتح Terminal
cd student-assignment-system
chmod +x setup.sh
./setup.sh
```

## 🎯 تشغيل النظام

### الطريقة الأسهل:
```bash
python run_system.py
```
سيفتح نافذة ترحيب مع زر لتشغيل النظام

### تشغيل مباشر:
```bash
python main_gui.py
```

## 📚 الميزات الرئيسية

### 1️⃣ إدارة الطلاب
- إضافة طالب واحد أو عدة طلاب دفعة واحدة
- حذف طلاب
- تصدير قائمة الطلاب
- إنشاء مجلد خاص لكل طالب تلقائياً

### 2️⃣ إدارة المواد
- إضافة مواد دراسية جديدة
- تسجيل الطلاب في المواد
- عرض عدد الطلاب لكل مادة
- تتبع المعلمين

### 3️⃣ رفع الواجبات ⬆️
**الميزة الأهم!**
- زر كبير واضح لرفع الواجبات
- دعم جميع أنواع الملفات (PDF, Word, صور, نصوص)
- تسمية تلقائية مع طابع زمني
- تنظيم تلقائي في مجلدات الطلاب والمواد
- سجل حالة لمتابعة عمليات الرفع

**كيفية رفع واجب:**
1. اذهب لتبويب "رفع الواجبات"
2. اختر المادة من القائمة
3. اختر الطالب
4. اضغط "📁 اختر ملف الواجب"
5. أدخل اسم الواجب (اختياري)
6. اضغط الزر الكبير **"⬆️ رفع الواجب"**

### 4️⃣ التقييم 📝
- إنشاء ملفات تقييم احترافية
- إدخال الدرجات (0-100)
- كتابة تعليقات المعلم
- إضافة ملاحظات
- حفظ تلقائي مع طابع زمني

### 5️⃣ التنظيم التلقائي 🔄
**ميزة ذكية!**
- تنظيم ملفات التقييم تلقائياً
- قراءة أسماء الطلاب من الملفات
- نقل الملفات إلى المجلدات الصحيحة
- تقرير تفصيلي بالنتائج

**كيفية الاستخدام:**
1. اذهب لتبويب "التنظيم التلقائي"
2. اختر المادة
3. اختر المجلد الذي يحتوي على ملفات التقييم
4. اضغط "🔄 تنظيم الملفات تلقائياً"

### 6️⃣ التقارير والإحصائيات 📊
- إحصائيات عامة للنظام
- تتبع تقدم كل طالب
- نسبة إنجاز الواجبات
- عدد الواجبات المكتملة

## 🆘 استكشاف الأخطاء

### المشكلة: الواجهة لا تظهر
**الحل:**
```bash
pip install --upgrade tk
```

### المشكلة: أخطاء في الترميز (encoding)
**الحل:**
- تأكد من حفظ الملفات بترميز UTF-8
- في Windows، استخدم:
```bash
chcp 65001
python run_system.py
```

### المشكلة: لا يمكن رفع الملفات
**الحل:**
- تحقق من صلاحيات الكتابة في المجلد
- تأكد من تسجيل الطالب في المادة أولاً

### المشكلة: التنظيم التلقائي لا يعمل
**الحل:**
- تأكد من أن ملفات التقييم تحتوي على أسماء الطلاب
- تأكد من تسجيل الطلاب في المادة
- تحقق من أن الملفات بصيغة `.txt`

## 💡 نصائح للاستخدام الأمثل

1. **ابدأ بإضافة الطلاب والمواد أولاً**
   - اذهب لتبويب "إدارة الطلاب"
   - أضف جميع الطلاب
   - انتقل لتبويب "إدارة المواد"
   - أضف المواد وسجل الطلاب فيها

2. **استخدم التسمية الواضحة للواجبات**
   - مثال: "واجب الوحدة 3" بدلاً من "واجب1"

3. **راقب سجل الحالة في تبويب رفع الواجبات**
   - يعرض تفاصيل كل عملية رفع

4. **استخدم التنظيم التلقائي بحذر**
   - تأكد من نسخ احتياطي قبل التنظيم
   - راجع النتائج في نافذة النتائج

5. **راجع التقارير بانتظام**
   - تبويب "التقارير والإحصائيات"
   - يساعد في متابعة أداء الطلاب

## 🎓 سيناريو استخدام كامل

### مثال: إدارة مادة الرياضيات

1. **إضافة الطلاب**
   ```
   - أحمد محمد
   - سارة خالد
   - علي حسن
   ```

2. **إضافة المادة**
   ```
   اسم المادة: الرياضيات
   اسم المعلم: الأستاذ خالد
   ```

3. **تسجيل الطلاب في المادة**
   - اختر "الرياضيات"
   - حدد جميع الطلاب
   - اضغط "تسجيل الطلاب المحددين"

4. **رفع واجب أحمد**
   - تبويب "رفع الواجبات"
   - المادة: الرياضيات
   - الطالب: أحمد محمد
   - اختر ملف PDF
   - اسم الواجب: "واجب الجبر"
   - اضغط ⬆️ رفع الواجب

5. **تقييم الواجب**
   - تبويب "التقييم"
   - المادة: الرياضيات
   - الطالب: أحمد محمد
   - الدرجة: 95
   - التعليقات: "عمل ممتاز!"
   - اضغط 📝 إنشاء ملف التقييم

6. **متابعة التقدم**
   - تبويب "التقارير والإحصائيات"
   - اختر "أحمد محمد"
   - اضغط "عرض التقدم"
