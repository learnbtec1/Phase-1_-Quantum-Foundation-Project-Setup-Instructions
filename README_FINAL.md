## 🎓 أمثلة استخدام

### الاستخدام من React:
```typescript
import useEvaluateMultiFile from '@/hooks/useEvaluateMultiFile';

const { evaluateMultiFile } = useEvaluateMultiFile();
const result = await evaluateMultiFile({
  assignment_text: "قارن بين شركتين",
  solutions: [
    { file_label: "Company A", file_content: "محتوى..." },
    { file_label: "Company B", file_content: "محتوى..." }
  ]
});

console.log(result.final_grade);        // الدرجة: MERIT
console.log(result.files_evaluated);    // 2
console.log(result.file_distribution);  // خريطة المعايير
```

### الاستخدام من API:
```bash
curl -X POST http://localhost:3000/api/evaluate-multi-file \
  -H "Content-Type: application/json" \
  -d '{
    "assignment_text": "الواجب",
    "solutions": [
      {"file_label": "f1", "file_content": "محتوى..."},
      {"file_label": "f2", "file_content": "محتوى..."}
    ]
  }'
```
