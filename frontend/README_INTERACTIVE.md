# المعلم الافتراضي التفاعلي — فورينا (مرئي، مسموع، متكلم)

## الميزات

1. **عرض الشخصية (Avatar)**  
   - شخصية ثلاثية الأبعاد (VRM) في منتصف الشاشة بحجم **400×600** بكسل.  
   - الملف المطلوب: **`public/models/Furina.vrm`**. إذا لم يكن موجوداً، تظهر رسالة توجيهية لوضعه.  
   - المكون: `VRMAvatar` مع `dynamic(..., { ssr: false })` و `vrmUrl="/models/Furina.vrm"`.

2. **الصوت (TTS — نطق الرد)**  
   - بعد استلام الرد من المعلم يُستدعى `handleSpeak(الرد)`.  
   - النطق عبر **Web Speech API** (`speechSynthesis`) بالعربية (`ar-SA`).  
   - جاهز لربط `avatarRef.current?.speakText(text)` عند استخدام مكتبة ناطقة (مثل `@sage-rsc/talking-head-react` مع GLB).

3. **الإدخال الصوتي (Speech-to-Text)**  
   - زر ميكروفون دائري بجانب مربع النص.  
   - **Web Speech API** (`SpeechRecognition` / `webkitSpeechRecognition`) مع `lang: 'ar-SA'`.  
   - ضغطة لبدء التسجيل، ضغطة للإيقاف؛ النص يظهر في مربع الإدخال ثم يُرسل للمعلم.

4. **ربط المحادثة مع الذكاء الاصطناعي**  
   - **الباكند:** `POST /api/v1/chat` — يستقبل `{ "message": "..." }`، يستخدم `OPENAI_API_KEY` و GPT-4o (معلم فورينا)، يُرجع `{ "reply": "..." }`.  
   - **الواجهة:** جسر `POST /api/chat` يوجّه إلى الباكند. بعد استلام الرد تُضاف فقاعة وتُستدعى `handleSpeak(الرد)`.

5. **واجهة المستخدم**  
   - الأفاتار في الأعلى (400×600).  
   - سجل المحادثة (فقاعات للطالب وفورينا).  
   - مربع نص + زر إرسال + زر ميكروفون.  
   - Tailwind CSS، متجاوبة.

## تشغيل المشروع

1. **وضع ملف الشخصية**  
   ضع **Furina.vrm** في `frontend/public/models/`. راجع `public/models/README.txt`.

2. **الباكند**  
   ```bash
   cd backend
   # OPENAI_API_KEY في .env
   python run_server.py
   ```

3. **الواجهة**  
   ```bash
   cd frontend
   npm run dev
   ```

4. افتح **http://localhost:3000/evaluate**.  
   - يجب أن تظهر الشخصية (إن وُجد الملف).  
   - الميكروفون يطلب الإذن ويحوّل الصوت إلى نص.  
   - الإرسال يحصل على رد منطوق.

## استكشاف الأخطاء

- **الشخصية لا تظهر:** تأكد من وجود `public/models/Furina.vrm`.  
- **لا صوت:** تحقق من دعم المتصفح لـ `speechSynthesis` ووجود صوت عربي.  
- **الميكروفون لا يعمل:** استخدم Chrome/Edge وامنح إذن الميكروفون.  
- **لا رد من المعلم:** تأكد من تشغيل الباكند ووجود `OPENAI_API_KEY` في `.env`.
