# BTEC Basics

BTEC (Business and Technology Education Council) qualifications focus on practical, vocational learning.

## Key Concepts
- **Units**: Each BTEC course is divided into units covering specific topics.
- **Assignments**: Work is assessed through assignments rather than exams.
- **Grading**: Pass, Merit, Distinction. Distinction requires deeper analysis and application.
- **Critical Analysis**: Essential for higher grades. Use "why" questions, compare perspectives, link to real examples.

## Tips for Success
- Understand the assessment criteria before starting.
- Use varied academic sources and cite correctly.
- Apply theories to practical scenarios.
